# 구마모토 2박 3일 경로 지도

2026년 10월 17일(토)부터 19일(월)까지의 구마모토 여행 일정을 지도 위에서 움직여 보는 정적 웹 페이지입니다. 빌드 과정 없이 `index.html` 하나로 동작합니다.

## 기능

- 1일차, 2일차, 3일차, 전체 탭을 누르면 지도가 해당 일차의 범위로 이동합니다.
- 재생 버튼을 누르면 점이 경로를 따라 움직이고, 시계가 여행 시각을 보여 줍니다.
- 장소에 도착할 때마다 사진, 한국어와 일본어 이름, 시간대, 이동 수단과 요금, 한 줄 메모가 담긴 카드가 열립니다.
- 1x, 2x, 4x 속도 전환, 일시정지, 처음부터 다시 재생, 재생 위치 막대를 지원합니다.
- 하단 패널에 일차별 교통비와 합계가 나옵니다.
- 시스템 설정에 따라 밝은 테마와 어두운 테마를 자동으로 고릅니다.
- 시스템의 움직임 줄이기 설정이 켜져 있으면 애니메이션 없이 모든 경로를 한 번에 보여 줍니다.

## 로컬에서 보기

`index.html`을 브라우저에서 바로 열어도 되고, 간단한 서버를 띄워도 됩니다.

```
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000/`을 엽니다. 지도 타일, Leaflet, 글꼴은 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 지도 타일 설정

CARTO basemaps는 API 키 없이 쓰면 "API KEY REQUIRED" 워터마크가 찍힙니다. 그래서 기본값은 OpenStreetMap 표준 타일이며, 어두운 테마에서는 색을 반전해 보여 줍니다. [CARTO 무료 키](https://carto.com/basemaps/apikey)를 발급받았다면 `data.js`의 `cartoKey`에 넣으세요. 그러면 CARTO light_all(밝은 테마)과 dark_all(어두운 테마)을 씁니다. 키는 브라우저에 그대로 노출되므로 사용량 제한이 걸린 공개용 키만 쓰세요.

## GitHub Pages로 공개하기

1. 이 폴더의 내용을 GitHub 저장소 루트에 올립니다.
2. 저장소의 Settings → Pages로 이동합니다.
3. Build and deployment에서 Source를 Deploy from a branch로 고르고, 브랜치를 main, 폴더를 / (root)로 지정한 뒤 저장합니다.
4. 잠시 뒤 안내되는 주소로 접속합니다.

`.nojekyll` 파일이 있어 Jekyll 처리 없이 그대로 배포됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 뼈대 |
| `style.css` | 디자인(밝은/어두운 테마, 반응형) |
| `data.js` | 장소 좌표, 일정, 사진 정보 (좌표별 출처는 파일 상단 주석) |
| `app.js` | 지도, 애니메이션, 카드 동작 |
| `photos/` | 사진 20장(가로 1280px 이하) |
| `LICENSES.md` | 사진, 지도, 라이브러리 출처와 라이선스 |

## 출처

사진 작가와 라이선스, 지도 타일, 라이브러리 출처는 [LICENSES.md](LICENSES.md)에 정리했습니다.

## 참고

- 정류장 사이의 선은 실제 도로나 선로가 아니라 개략 경로입니다.
- 일정의 시각과 요금은 작성 시점(2026-10-14)의 확인 결과이며, 확인하지 못한 항목은 "미확인"으로 표시했습니다.
- 재즈 바 스윙의 정확한 주소는 확인하지 못해 하나바타초(花畑町) 일대로 표시했습니다. 숙소는 시모토리 아케이드 일대로만 표시했습니다.
